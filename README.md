## About This Repository

This repo documents a structured 30-day journey into QA Engineering, covering:
- ✅ Manual testing methodologies
- ✅ API & backend testing
- ✅ Performance testing
- ✅ Test automation (Playwright, Cypress)
- ✅ CI/CD integration (GitHub Actions, Docker)
